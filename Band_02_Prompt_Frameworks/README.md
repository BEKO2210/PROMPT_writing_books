# Band 2: Prompt-Frameworks – Strukturiert zum perfekten Prompt

**Autor:** Belkis Aslani
**Reihe:** Prompt Engineering Meistern (Band 2 von 10)
**Level:** Anfänger

## Worum geht's?

Frameworks geben deinen Prompts eine klare Struktur. Du lernst CRAFT, RTF, RISEN und andere bewährte Methoden kennen. Dazu: Zero-Shot, Few-Shot und One-Shot Prompting – und wie du dir eine eigene Template-Bibliothek aufbaust.
