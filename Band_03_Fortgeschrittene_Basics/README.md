# Band 3: Fortgeschrittene Basics – Vom Anfänger zum sicheren Anwender

**Autor:** Belkis Aslani
**Reihe:** Prompt Engineering Meistern (Band 3 von 10)
**Level:** Anfänger-Fortgeschritten

## Worum geht's?

Du kennst die Grundlagen und die Frameworks – jetzt geht's ans Eingemachte. Prompt-Chaining, Delimiter, negative Prompts, Temperatur-Einstellungen, System-Prompts und der Vergleich verschiedener LLMs. Nach diesem Band bist du ein sicherer Prompt-Anwender, der weiß, was hinter den Kulissen passiert.
