# Band 6: Spezialisiertes Prompting – Für jede Branche das Richtige

**Autor:** Belkis Aslani
**Reihe:** Prompt Engineering Meistern (Band 6 von 10)
**Level:** Fortgeschritten

## Worum geht's?

Branchenspezifisches Prompting: Bildung, Marketing, Datenanalyse, Wissenschaft, Recht, Medizin, HR und Finanzen. Jede Branche hat ihre eigenen Anforderungen – und ihre eigenen Prompt-Tricks. Plus: Branchenübergreifende Prinzipien für professionelles KI-Arbeiten.
