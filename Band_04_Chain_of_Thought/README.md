# Band 4: Reasoning-Techniken – KI zum Denken bringen

**Autor:** Belkis Aslani
**Reihe:** Prompt Engineering Meistern (Band 4 von 10)
**Level:** Fortgeschritten

## Worum geht's?

Chain-of-Thought, Tree-of-Thought, Self-Consistency, ReAct und Meta-Prompting. Du lernst, wie du LLMs dazu bringst, Schritt für Schritt zu denken und bessere Ergebnisse bei komplexen Aufgaben zu liefern.
